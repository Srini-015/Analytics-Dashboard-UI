# Analytics Dashboard (React)

A mini analytics dashboard built with React + Recharts.

## Features
- Bar chart for monthly sales comparison
- Line chart for monthly revenue trend
- Dynamic filters for year, category, and department
- KPI cards for quick summary metrics
- Responsive layout for desktop and mobile

## Run Locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```
3. Open the local URL shown by Vite.

## Build
```bash
npm run build
npm run preview
```
